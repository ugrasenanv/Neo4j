# Neo4j Project - Complete File Explanations

## Project Overview
A Neo4j graph database project that integrates vector embeddings and LLM capabilities. It loads job titles and skills data, creates relationships between them, generates embeddings for vector search, and enables both schema-based and semantic queries using LangChain.

---

- Project documentation and setup instructions

- Provides conda environment setup commands

### 3. **cypher_cmds.cyp**
Cypher query file for Neo4j containing:
- **Database cleanup**: Drops all nodes, constraints, and indexes
- **Constraint creation**: 
  - `skillUnique`: Ensures skill names are unique
  - `titleUnique`: Ensures title names are unique
- **Data import**: Loads CSV data from GitHub
- **Relationship creation**: Creates `REQUIRES` relationships between titles and skills
- **Node labeling**: Tags skills with category labels (Certification, SpecializedSkill)

## 📊 Data Files (in `/data/`)

### embeddings.csv
- Contains skill name and vector embeddings
- Generated by `create_embeddings.py`
- Used for vector search index

### skills_details.csv
- Schema: ID, Skill, Description, Category
- Source data for skill nodes
- Categories: Certification, SpecializedSkill, etc.

### titles_and_skills.csv
- Schema: Title, Skills (pipe-separated), additional columns
- Maps job titles to required skills
- Source data for title nodes and relationships

## 🔑 Key Classes & APIs

### Neo4j Driver Operations
- **Connection**: Uses `neo4j.GraphDatabase.driver()`
- **Sessions**: Execute queries in managed sessions
- **Transactions**: ACID-compliant data operations

### LangChain Integration
- **GraphCypherQAChain**: LLM-to-Cypher translator
- **Neo4jVector**: Vector store with Neo4j backend
- **RetrievalQA**: Question-answering chain
- **ChatOpenAI**: LLM for query generation

### Embeddings
- **SentenceTransformer**: Local, fast (384-dim)
- **OpenAI**: Powerful but requires API key (1536-dim)
